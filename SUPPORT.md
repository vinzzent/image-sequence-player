# Support

This project is a Power BI Custom Visual maintained as an open-source effort.
Support is provided on a best-effort basis.

---

## Where to Get Help

### General Questions & Discussions
For usage questions, configuration help, or general feedback, please use
**[GitHub Discussions](https://github.com/vinzzent/image-sequence-player/discussions)**.

This is the preferred channel for:
- How-to questions about the visual
- Suggestions and feature requests
- Sharing how you're using the visual

### Direct Contact
For inquiries that are not suitable for public discussion:

[contact.concacore@gmail.com](mailto:contact.concacore@gmail.com)

Please allow a few days for a response, as replies are not guaranteed within a specific timeframe.

---

## Reporting Bugs

Use **[GitHub Issues](https://github.com/vinzzent/image-sequence-player/issues)** only for confirmed bugs and reproducible problems.

Before opening an issue, please:
1. Check if the issue has already been reported
2. Verify it occurs with the latest version of the visual
3. Include the Power BI Desktop version you are using
4. Provide steps to reproduce the problem

---

## What Not to Use Issues For

Please do **not** open a GitHub Issue for:

- Usage or configuration questions → use [Discussions](https://github.com/vinzzent/image-sequence-player/discussions)
- Feature requests → use [Discussions](https://github.com/vinzzent/image-sequence-player/discussions)
- General feedback → use [Discussions](https://github.com/vinzzent/image-sequence-player/discussions)

Issues opened for the above may be closed and redirected without a response.

---

## Response Expectations

This visual is maintained independently. There are no SLAs or guaranteed response times.
Community contributions and feedback are always welcome.
